# KPI Sentinel AI

> AI-powered early warning system for organisational performance.

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Visit%20Website-blue)](https://yankey-code.github.io/KPI-SENTINEL-AI-HACKATHON-TENCENT/)

## Overview

**KPI Sentinel AI** is an AI-powered organisational performance monitoring prototype designed to help businesses identify potential performance risks before they become critical.

The system analyses Key Performance Indicator (KPI) data across financial performance and customer experience, identifies unusual trends, evaluates risk levels, explains potential causes, and recommends practical management actions.

The project was developed as part of the **Tencent Cloud × UTM AI CAN DO IT Hackathon 2026** under **Case Study 2: Intelligent Early Warning System for Organisational Performance**.

## Problem

Organisations often rely on spreadsheets and manual KPI reviews to monitor performance.

This can make it difficult to:

- Identify declining trends early
- Detect abnormal KPI changes
- Compare actual performance with targets
- Understand the causes of performance issues
- Decide which issues require immediate attention
- Convert KPI data into actionable decisions

As a result, managers may discover business problems only after they have already had a significant impact.

## Solution

KPI Sentinel AI provides an AI-assisted workflow for transforming raw KPI data into actionable business insights.
